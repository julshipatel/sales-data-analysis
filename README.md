# Sales Data Analysis Dashboard

## 📌 Project Overview

This project is a **Sales Data Analysis Dashboard** created using **Microsoft Power BI**. The project analyzes sales data to understand business performance, identify sales trends, and generate useful insights for decision-making.

## 🎯 Objectives

* Analyze overall sales performance
* Identify top-performing products
* Analyze sales trends
* Compare sales performance across different categories
* Analyze regional sales performance
* Identify important business insights from the data

## 🛠️ Tools & Technologies

* Microsoft Power BI
* DAX
* Data Cleaning
* Data Analysis
* Data Visualization

## 📊 Dashboard

The Power BI dashboard provides interactive visualizations to explore sales performance and identify important trends and patterns.

### Key Analysis

* Sales Performance
* Product Analysis
* Category Analysis
* Regional Analysis
* Sales Trends
* Profit Analysis
